# Varu — island household marketplace

Everyday groceries, kids essentials, cosmetics and services for Maldivian islands.

Live (GitHub Pages): https://hamzath3433.github.io/varu-market/

## Before first public order
1. Sign in as master admin (`admin@varu.mv` / `varuadmin`).
2. Open **Settings** and set the real master-admin email.
3. Submit Contact Us once, then confirm the FormSubmit activation email in that inbox. After that, every contact and verification mail delivers automatically.
4. Add or pause islands from **Islands**. Change membership fees under **Subscriptions**.

## How mail works
Registration sends a 6-digit code the moment an email looks valid, and again when a 7-digit Maldivian mobile is entered. Codes go to the household inbox. Contact Us writes to the master admin email and is copied into the admin **Contact inbox**.

SMS carriers are not attached yet — the phone code is emailed to the verified address so launch is not blocked on Twilio.
